Three ways a key leaks. One fix.

Every SDK, .env file and AI agent asks for the raw key. Once it exists in plaintext it gets pasted, committed, logged, or handed to someone.

What a handle can do

Each handle carries its own rules, explained in plain English, enforced before anything leaves your machine.

Policy per handle

Presets per provider: stripe:payments takes payments and refuses refunds and payouts. Paths, methods, time windows, expiry, approvals.

Hard caps

--cap 500/day: the 501st request is refused before it leaves the machine. A stolen handle cannot run up a bill.

Canaries

--canary makes a handle that never works. Plant it in .env.example; any use means someone has your files, and the vault locks.

Incident responses

A burst of refused requests throttles, pauses, asks you, or locks the vault. Your choice per handle; one click to resume.

Live approvals

Sensitive calls wait for you: allow once, allow always for this rule, or deny. Desktop notifications on Windows, macOS and Linux.

Camouflage handles

Handles shaped like the provider's own keys for SDKs that validate formats. Every format carries the usk marker.

AWS and OAuth2

boto3, the AWS CLI and the JS SDK sign with a placeholder; the broker re-signs with the real key. Refresh tokens stay in the vault.

Tamper-evident log

Every call, allowed or refused, in a hash-chained audit log, written before the first byte goes out. usk log verify.

Desktop app

Secrets, handles, approvals and activity in one window. Windows Hello unlock, lock on sleep and screen lock, signed auto-updates.

Which one would leak?

Paste a key or a handle. This runs in your browser; nothing is sent anywhere, and this page has no analytics. Still: don't paste your real keys into web pages, use the samples.

    Install

    Signed builds for every platform. No account, no telemetry, nothing leaves your machine.

    # Windows
scoop bucket add unseenkey https://github.com/Bhagyesh97/scoop-unseenkey
scoop install usk

# macOS and Linux
brew install Bhagyesh97/unseenkey/usk

# from source (Rust 1.85+)
cargo install --locked --git https://github.com/Bhagyesh97/unseenkey usk

    Desktop installers for Windows, macOS and Linux, and CLI archives for every platform, are on the releases page. Every archive has a Sigstore signature, every installer a minisign signature, and each release ships an SBOM. The installers are not yet code-signed, so Windows SmartScreen and macOS Gatekeeper warn on first launch.

    Security

    • Vault: Argon2id and XChaCha20-Poly1305, keys locked in memory, a 24-word recovery phrase, optional Windows Hello.
    • Fail closed: each secret is locked to its provider's hosts; unmatched requests, browser-origin requests and anything the broker cannot classify are refused.
    • Scrubbing: the real key and its encodings are removed from responses, logs and error messages.
    • Open: Apache-2.0, a published threat model that also says what it does not protect against, and a disclosure policy.

    Alpha software, not yet externally audited. Use it with keys you can rotate. A process with code execution on your machine can still use an unlocked vault within policy; for a hostile agent you also want an OS sandbox.
